FAQ

Common questions

Does Watchio include TV channels or movies?

No. Watchio is a player. You must connect your own lawful provider or playlist.

Can I download Watchio now?

Not as a normal public release yet. Development builds exist for testing, but Watchio is still being actively developed.

Does Watchio support Xtream Codes?

Yes. Xtream provider workflows are part of the current app.

Does Watchio support M3U?

Yes. M3U playlist support is part of the current app.

Does Watchio support an EPG?

Yes. Watchio supports programme-guide information where compatible EPG data is available from the configured source.

Can I use a TV remote?

Yes. Android TV and Fire TV remote navigation, focus handling and keyboard-style input are key parts of the current interface work.

Is Windows available?

The current rewrite is focused on native Android. Windows is a future target rather than part of the current native build.
