# Watchio Website

Static GitHub Pages website for Watchio IPTV.

This repository contains only public website files:

- `index.html`
- `styles.css`
- `script.js`
- public-safe Dev Log screenshots

The Watchio app source code, internal implementation details, provider data, private keys, builds, and release signing material must stay in a separate private repository.

## GitHub Pages

Deploy from the `main` branch root folder.

## Content status

Download links are marked Coming Soon until stable public builds are ready.
